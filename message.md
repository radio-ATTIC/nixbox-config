i come here to announce something that none of you and i mean NONE of you cares about, i published my nix os setup.
now for the normal people out there that arent me and dont know what that is, NixOS is an operating system where your entire computer's setup, every app, every setting, lives in one text file, so rebuilding that file always gives you the exact same system, every time. 
its considered one of the most complicated distro's to use but also in my opinion one of the most fun to learn the ins and outs of. it offers features that ive never seen anywhere and can do some amazing things if learnt properly.
What does what i published do? if you were to put those same files in the configuration folder of a nix os system you would get the same exact features the same apps with the same app versions that i currently have
However it still lacks the ability to also build the same exact app configurations, thats a whole different beast ive yet to tackle. but ive been focusing on getting the system to a state that can be worked on easily, ive annotated as much as i can so that future dumb me figures it out easier.
again, what does this mean for any of you? NOTHING! im sharing this because i can, yes its public and you can use it yourself but without the proper knowledge to edit the files your system will just crash so if anything its just a backup i can use if i lose my github account.
ill keep updating the repo and ofcourse my system is nowhere near perfect. im currently still trying to unify the themes of the system so they look nice together :D
